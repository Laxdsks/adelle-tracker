# Pemeriksaan KomikLingo 0.1.4

- assembleDebug dan lintDebug berhasil. Paket com.komiklingo.app, versionCode5/versionName0.1.4, minSDK26/targetSDK35, ARM64/ARMv7. Tidak ada error lint; peringatan yang tersisa meliputi literal UI, JavaScript untuk situs pembaca dan versi dependensi pengujian.
- Tanda tangan APK diverifikasi dengan apksigner; SHA256 sertifikat pengembangan tetap bb1ef448fb34777d2d03a49e7bfdb2bfb355ba7d57fe7b6a11f410d020e346a1. Pembaruan dapat dipasang di atas versi sebelumnya tanpa menghapus model/pengaturan.
- Tiga program tes JVM lulus: ReaderRulesTest, NameRulesTest, TranslationFlowTest. Termasuk nama/batas kata/Unicode/pemisahan cerita, sapaan, kontrak nama sebelum/sesudah perubahan gaya, URL dan pencarian. Tambahan: pemenggalan kata yang dikenal dan pengecualian nama bertanda hubung, kontraksi yang tidak ambigu, spasi/tanda baca/paragraf, kelompok 9 dialog dibagi 8+1, pengembalian urutan bila marker nama dipindah, fallback hasil batch yang menyatu, pembatalan pembacaan lama dan kegagalan sebagian.
- Dua tes server Python lulus dengan model tiruan: autentikasi, validasi, pemisahan konteks, kontrak hasil serta penanda nama. Prompt AI diperjelas untuk membaca konteks, menjaga negasi/rujukan/emosi dan tidak menebak fakta yang hilang. Tes tersebut tidak menilai kualitas Ollama sebenarnya.
- Instrumentasi Android 30 x86_64 lulus: OK (7 tests). TypographyTest (4) memeriksa pemisahan paragraf berdasarkan geometri, pemenggalan kata, sampling tinta merah/kuning, kontras tanpa mengubah gambar asli, pemilihan blok OCR lebih kuat, ukuran font di atas batas lama 38 piksel, spasi paragraf, batas keterbacaan dan overflow. Salah satunya memakai ML Kit OCR asli untuk membaca WAIT FOR ME! berwarna merah dan mengukur kembali tinta/ukuran sumber. ViewportCaptureTest (2) memakai OCR asli pada gambar WebView sebelum/sesudah scroll, membatasi area header/footer, dan menangani view terlepas. ProtectedNamesFlowTest (1) memeriksa dialog nama, simpan/buka ulang/pergantian cerita dan perlindungan nama saat hasil dipasang.
- Pratinjau gambar sintetis hasil tata huruf diperiksa visual: teks merah besar, teks biru dua paragraf, dan indikator overflow. Ini bukan foto hasil pada situs komik pengguna. Tersimpan di validation/layout-preview.png.
- Layout teks dihitung saat hasil berubah, bukan tiap onDraw. Belum ada pengukuran FPS/memori pada HP pengguna. Percobaan kontras hanya satu tambahan bila OCR kosong/lemah, bukan jaminan seluruh huruf dekoratif terbaca.
- Manifest/ABI APK akhir diperiksa: fixture uji tidak disertakan; tidak ada pustaka x86 pada APK pengguna. Arsip sumber tidak menyertakan keystore, konfigurasi SDK lokal atau direktori build. Hasil unduhan publik diperiksa SHA256 setelah diunggah.

Batas praktis: belum diuji pada HP pengguna atau seluruh situs/huruf/gambar komik. Tidak ada benchmark kualitas terjemahan model ML Kit/Ollama asli terhadap cerita ini. Mode gratis di HP masih tidak memahami seluruh alur, hubungan tokoh dan idiom; pengelompokan memperbaiki masukan tetapi tidak menjamin semua kalimat nyambung. OCR confidence bukan bukti teks benar. Huruf yang hilang dari gambar/di luar viewport tidak direkonstruksi. Deteksi tepi meminta pengguna menggulir agar teks utuh. Warna dominan/ukuran/alignment adalah perkiraan per paragraf; campuran warna per kata dan font dekoratif tidak dipetakan persis. Bagian yang terlalu panjang tetap bisa perlu dibaca lewat Hasil. Perlindungan nama yang sudah ada dipertahankan, tetapi pengenalan nama baru bisa luput. Server AI tetap opsional dan memerlukan komputer yang disiapkan sendiri.
