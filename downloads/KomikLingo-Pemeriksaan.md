# Pemeriksaan KomikLingo 0.1.5

- assembleDebug dan lintDebug (APK pengguna tanpa captureTest) berhasil. Paket com.komiklingo.app, versionCode6/versionName0.1.5, minSDK26/targetSDK35, ARM64/ARMv7. Tidak ada error lint. Tanda tangan pengembangan tetap SHA256 bb1ef448fb34777d2d03a49e7bfdb2bfb355ba7d57fe7b6a11f410d020e346a1.
- Empat program JVM lulus: ReaderRulesTest, NameRulesTest, TranslationFlowTest, OcrQualityTest. Meliputi nama/Unicode/URL/pemisahan cerita, perlindungan nama pada OCR dan gaya, pengelompokan dan pembatalan, kontraksi/tanda baca, pola gagap tanpa mengubah ejaan nama, penilaian kosakata dan campuran huruf-angka. Pemeriksa kosakata tidak melakukan penggantian kata secara otomatis.
- Dua tes server AI Python tetap lulus dengan model tiruan. Ini pemeriksaan kontrak/isolasi konteks, bukan kualitas bahasa model AI sebenarnya.
- Dua uji Android 30 x86_64 CapsOcrTest lulus dengan gambar panel contoh privat dari sumber publik. Ukuran sumber 800x1150 serta versi dibesarkan 2,56 kali (2048x2944), untuk mencerminkan huruf besar pada tangkapan viewport. Jalur ML Kit + crop/normalisasi/pelurusan + OCR Tesseract nyata berhasil membaca LAUGH, DIRECTLY dan SOUL pada kedua ukuran; koordinat hasil tetap di area gambar. Lihat validation/caps-ocr-result.log. Gambar panel tidak disertakan dalam APK/arsip. Huruf awalan gagap masih dapat ambigu pada OCR mentah; pengolahan gagap diperiksa terpisah oleh JVM.
- Tujuh uji Android tambahan lulus, dalam run terpisah: HomeHistoryTest (2), TypographyTest (4), ProtectedNamesFlowTest (1). Home memeriksa peluncuran tanpa membuka URL lama, tombol Lanjutkan membuka bab 50 dan posisi tersimpan, tautan baru membuka bab 51, callback bab 48 yang terlambat tidak mengubah URL aktif, pemilihan bab 48 dari riwayat, pesan tautan yang sudah dikonsumsi tidak tersimpan sebagai intent, urutan riwayat tidak berubah akibat simpan posisi bab lama, batas 30 entri dan persistensi data.
- Typography memeriksa OCR ML Kit asli pada huruf merah, sampling merah/kuning, paragraf, pembandingan blok, font di atas 38 piksel dan overflow. Tes nama memeriksa simpan/buka ulang/pemisahan cerita dan hasil dengan nama terlindung. Lihat validation/caps-home-ui-result.log. Pratinjau Beranda dibuat dari view native aplikasi dengan data bab fixture, bukan pengukuran performa perangkat fisik.
- Tesseract4Android 4.9.0 dan English tessdata_fast dipaketkan untuk OCR cadangan di HP, tanpa server/API key. SHA256 model eng.traineddata: 7d4322bd2a7749724879683fc3912cb542f19906c83bcc1a52132556427170b2. Lisensi/atribusi CMUdict, Tesseract/Tesseract4Android, Leptonica disertakan dalam assets. Model disalin ke data privat; gambar baris sementara di memori.
- Manifest/ABI/tanda tangan APK pengguna diperiksa: tidak ada fixture activity atau pustaka x86, tidak ada izin kamera/mikrofon/penyimpanan luas baru. Source ZIP tidak berisi keystore, build, local.properties atau gambar bab. SHA256 unduhan APK publik diperiksa setelah unggah.

Batas: diuji pada emulator perangkat lunak Android 30, belum HP pengguna; bukan tolok ukur FPS/latensi/memori HP. OCR tambahan menambah pekerjaan untuk teks sulit dan masih dapat salah pada font/nama/angka ambigu. Uji panel hanya membuktikan kata-kata yang diperiksa pada contoh tersebut, bukan seluruh huruf pada semua komik. Tidak ada benchmark kualitas terjemahan ML Kit atau Ollama asli terhadap seluruh cerita. Mode dasar belum memahami seluruh alur/emosi. Riwayat URL/posisi disimpan lokal untuk halaman web; file dan pencarian DDG tidak masuk riwayat bab. Situs yang memuat gambar lambat/berubah tata letak dapat membuat posisi gulir belum tepat. Teks di luar layar/hilang tidak direkonstruksi. Warna/ukuran/gaya masih perkiraan, bukan tiruan font persis atau pengembalian artwork.
