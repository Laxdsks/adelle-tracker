# Pemeriksaan TCD 0.4.0

Fitur Game otomatis pada balon mengambang: pemilih area langsung di atas game, OCR pada area itu, dua observasi teks sama sebelum penerjemahan, deduplikasi dialog yang belum berganti, konteks dialog sebelumnya, subtitle di luar area pemindaian, sentuhan diteruskan lewat FLAG_NOT_TOUCHABLE dan opacity jendela 0.75, jeda/lanjut melalui balon, serta penghentian/pembersihan sesi. Balon dipindahkan keluar dari area dialog sebelum membaca frame. Hanya satu pekerjaan dijadwalkan; hasil dari generasi lama tidak ditampilkan. Snapshot hasil manual tidak dipakai oleh mode live. Pemantauan berakhir bila ukuran/orientasi layar berubah. Membuka menu menjeda mode live.

Sepuluh suite JVM lulus, termasuk LiveDialogueGateTest: animasi pengetikan, teks stabil, dialog baru, deduplikasi, layar kosong, retry, dan reset sesi. Log validation/jvm-0.4.0.log. Build ARM dan lint: validation/build-arm-0.4.0.log. Metadata dan tanda tangan: validation/apk-0.4.0.log.

Uji Android liveGameFollowsDialogueWithoutScreenshotOrBlockingTouch memakai MediaProjection dan OCR ML Kit nyata di aplikasi uji dengan UID berbeda. Mesin terjemahan diganti fixture deterministik untuk mengisolasi alur dari unduhan/model bahasa. Uji memeriksa subtitle tanpa snapshot/resultView layar penuh, tidak mengulang terjemahan dialog tetap, tap sistem melewati subtitle ke tombol Next di aplikasi lain, dialog selanjutnya diterjemahkan otomatis, jeda, penolakan hasil terlambat setelah jeda, lanjut dan pelepasan service. Log validation/android-live-0.4.0.log. Uji regresi izin dibatalkan dan tangkapan manual aplikasi lain/rotasi/hentikan dari notifikasi: validation/android-floating-0.4.0.log.

Batas: belum diuji pada game/HP pengguna. Emulator memakai Android 11; aturan overlay Android lebih baru mengikuti API dan pengaturan jendela yang ditetapkan, belum diuji di perangkat Android 12–15 pada versi ini. Terjemahan nyata seluruh dialog game belum dinilai: fixture pengujian alur bukan bukti mutu bahasa ML Kit. Ada latensi dua observasi stabil, OCR dan terjemahan; bukan nol jeda. Layar terlindungi tidak dilewati. Font dekoratif/kontras rendah, animasi huruf berhenti sesaat, dialog panjang dan pergantian sangat cepat dapat membatasi hasil. Subtitle panjang diberi elipsis dan teks lengkap tersedia di menu. Mode manual tetap tersedia. Paket memakai sertifikat pengembangan lama dan mendukung ARM64/ARMv7 Android 8+.
